# 📚 DLib – AI Powered Library Management System

---

## 🚀 Overview

DLib is an AI-powered Library Management System designed to modernize traditional library operations through intelligent search, automated book management, and AI-assisted user interactions.

The platform enables students, librarians, and administrators to efficiently manage books, users, borrowing records, and library resources through a centralized web application.

---

## ✨ Features

### 👨‍🎓 Student Features

* Browse and search books instantly
* View book availability
* Issue and return books
* Track borrowing history
* AI-powered book discovery
* leaderboard

### 👨‍💼 Librarian Features

* Add, update, and remove books
* Manage inventory
* Track issued books
* Monitor overdue returns
* Manage library records

### 🤖 AI Features

* AI Book Summary
* Intelligent book recommendations
* Skill Roadmap Generator
* Q&A, cheatsheets, notes about any book
* viva questions, MCQ generation

### 📊 Dashboard

* Book availability metrics
* User activity tracking
* Borrowing analytics

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/UnmeshOnGit/DLib-AiLibraryManagement.git
cd DLib-AiLibraryManagement
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file:

```env
PORT=5000
MONGODB_URI=your_database_url
JWT_SECRET=your_secret
OPENAI_API_KEY=your_api_key
```

### Run Development Server

```bash
npm run dev
```
